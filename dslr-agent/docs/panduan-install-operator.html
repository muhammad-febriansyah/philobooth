Cara Install Aplikasi Kamera

Supaya booth bisa pakai kamera DSLR & printer di PC Windows
Untuk: operator / penjaga booth · Perkiraan waktu: 5–10 menit · Sekali install saja
Kenapa perlu aplikasi ini? Website Philobooth tidak bisa langsung memegang kamera DSLR & printer. Aplikasi kecil ini jadi jembatannya. Website tetap dibuka di Chrome seperti biasa — aplikasi ini cuma jalan diam di belakang.

Yang perlu disiapkan

  • PC / laptop Windows 10 atau 11.
  • Kamera DSLR + kabel USB data (bukan kabel cas biasa).
  • Printer foto sudah terpasang di Windows.
  • Koneksi internet (untuk buka website booth).

Langkah instalasi

1
Download aplikasinya

Buka philobooth.id di Chrome → login → halaman Dashboard → klik tombol Download aplikasi. File philobooth-camera.exe akan terunduh.

Kalau admin sudah mengirim filenya langsung, pakai file itu.

2
Jalankan file yang terunduh

Buka folder Downloads, klik dua kali file philobooth-camera.exe.

Kalau muncul layar biru “Windows protected your PC”: itu normal (aplikasi baru). Klik teks “More info” lalu tombol “Run anyway”. Aplikasi aman — dibuat untuk booth kamu.
3
Selesaikan pemasangan

Kalau ada installer: klik Next → Next → Install → Finish (biarkan centang “Jalankan otomatis saat Windows menyala”).

Setelah itu muncul ikon kamera kecil di pojok kanan bawah (dekat jam). Artinya aplikasi sudah jalan.

4
Colok kamera & printer

Colok kabel USB kamera langsung ke PC (jangan lewat colokan cabang/hub). Nyalakan kamera, set ke mode foto. Colok juga printer.

Penting untuk kamera Canon: kalau ada aplikasi Canon EOS Utility terbuka, tutup dulu sampai benar-benar mati. Aplikasi itu mengunci kamera sehingga booth tidak bisa memakainya.
5
Buka halaman booth

Di Chrome, buka philobooth.id/kiosk. Kalau Chrome bertanya izin “Local network” → klik Izinkan / Allow (cukup sekali).

6
Pilih mode DSLR & cek indikator

Di halaman ambil foto, pilih DSLR. Indikator harus jadi hijau: “Kamera terhubung” beserta nama kameranya.

Berhasil kalau: indikator hijau, dan saat ambil foto hasilnya dari kamera DSLR (bukan webcam). Setelah ini booth siap dipakai. Jangan tutup ikon aplikasi di tray selama booth beroperasi.

Kalau berhasil, cek ini

☐Ikon aplikasi ada di pojok kanan bawah (dekat jam).
☐Di kiosk mode DSLR, indikator hijau “Kamera terhubung”.
☐Ambil 1 foto → hasil tajam dari DSLR.
☐Cetak → keluar di printer.

Kalau ada masalah

MasalahYang harus dilakukan
Kiosk bilang “Aplikasi kamera belum jalan” Cek ikon di pojok kanan bawah. Kalau tidak ada, buka lagi aplikasinya (Start Menu → Philobooth Camera). Lalu klik Coba lagi di kiosk.
Kiosk bilang “Kamera tidak terdeteksi” 1) Nyalakan kamera. 2) Set kamera ke mode foto (bukan mode video/galeri). 3) Ganti kabel USB (banyak kabel cuma buat cas). 4) Colok langsung ke PC, bukan lewat hub. 5) Tutup Canon EOS Utility kalau terbuka.
Chrome tidak minta izin / kamera tetap tidak jalan Muat ulang halaman (F5). Kalau muncul izin “Local network”, klik Izinkan.
Kamera tidak muncul di komputer sama sekali Ini masalah kabel/colokan/kamera, bukan aplikasi. Cek kamera muncul di File Explorer. Kalau tidak muncul di situ pun, ganti kabel/port.
Tanpa DSLR, mau pakai webcam saja Bisa. Di kiosk pilih mode Webcam — tidak perlu aplikasi kamera.
Tiap hari sebelum buka booth: nyalakan PC → pastikan ikon aplikasi ada di tray → colok & nyalakan kamera → buka philobooth.id/kiosk → cek indikator hijau.
